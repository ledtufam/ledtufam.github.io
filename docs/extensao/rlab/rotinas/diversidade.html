Diversidade da vegetação: rarefação, estimadores e diversidade beta

Fitossociologia
Diversidade
Curva do coletor, rarefação, estimadores de riqueza (Chao 1, Jackknife) e partição da diversidade em alfa, beta e gama, com os dados abertos caixeta.
Autor

LEDT/UFAM

Nível: intermediário · Pacotes: apenas R básico · Disciplina: FGD320 - Fitossociologia · Baixar script · Baixar dados caixeta

Na prática de heterogeneidade, o caixetal da Jureia teve mais espécies (22) que os outros dois (13). Mas ele também foi amostrado com o mesmo esforço? Com menos árvores, esperamos encontrar menos espécies, mesmo que a comunidade seja igualmente rica. Nesta rotina, vemos como comparar a riqueza de forma justa, estimar quantas espécies faltam e separar a diversidade dentro e entre as áreas.

Roteiro da aula prática (30/10 · EE7)
  1. Construir a curva do coletor (seção 2);
  2. Comparar os caixetais pela rarefação (seção 3);
  3. Estimar a riqueza total com Chao 1 e Jackknife (seção 4);
  4. Partir a diversidade em alfa, beta e gama (seção 5) e responder aos exercícios (seção 6).

2. Curva do coletor (acumulação de espécies)

A curva do coletor mostra quantas espécies novas aparecem à medida que acrescentamos parcelas. Se ela se estabiliza (assíntota), a amostragem foi suficiente. Como a ordem das parcelas muda o resultado, sorteamos a ordem muitas vezes e usamos a média:

coletor <- function(m, n_perm = 200) {
  m <- m > 0
  res <- replicate(n_perm, {
    ordem <- sample(nrow(m))
    sapply(seq_along(ordem), function(k) sum(colSums(m[ordem[1:k], , drop = FALSE]) > 0))
  })
  data.frame(parcelas = 1:nrow(m), media = rowMeans(res),
             inf = apply(res, 1, quantile, 0.025), sup = apply(res, 1, quantile, 0.975))
}

3. Rarefação: comparar a riqueza com o mesmo número de indivíduos

A rarefação (Hurlbert 1971) responde: quantas espécies esperaríamos encontrar se tivéssemos amostrado só \(n\) indivíduos? Assim, comparamos as áreas com o mesmo esforço:

\[E(S_n) = \sum_{i=1}^{S} \left[ 1 - \frac{\binom{N - N_i}{n}}{\binom{N}{n}} \right]\]

em que \(N\) = total de indivíduos e \(N_i\) = indivíduos da espécie i.

rarefacao <- function(x, n) {
  x <- x[x > 0]; N <- sum(x)
  sapply(n, function(k) sum(1 - exp(lchoose(N - x, k) - lchoose(N, k))))
}

n_min <- min(rowSums(ab_local))          # o menor caixetal (jureia, 178 árvores)
sapply(rownames(ab_local), function(l) round(rarefacao(ab_local[l, ], n_min), 1))

4. Quantas espécies faltam? Estimadores de riqueza

Os estimadores não paramétricos usam as espécies raras para estimar quantas ainda não foram encontradas:

Estimador Fórmula Baseado em
Chao 1 \(S_{obs} + \frac{F_1(F_1 - 1)}{2(F_2 + 1)}\) singletons (\(F_1\), espécies com 1 indivíduo) e doubletons (\(F_2\), com 2)
Jackknife 1 \(S_{obs} + Q_1 \frac{m - 1}{m}\) \(Q_1\) = espécies em uma só parcela; \(m\) = número de parcelas 
estimadores <- function(m) {          # m = parcela × espécie (abundâncias)
  x  <- colSums(m); x <- x[x > 0]
  Sobs <- length(x); F1 <- sum(x == 1); F2 <- sum(x == 2)
  inc <- colSums(m > 0); inc <- inc[inc > 0]
  Q1 <- sum(inc == 1); k <- nrow(m)
  c(S_obs = Sobs, F1 = F1, F2 = F2, Chao1 = Sobs + F1 * (F1 - 1) / (2 * (F2 + 1)),
    Q1 = Q1, Jack1 = Sobs + Q1 * (k - 1) / k)
}

est <- rbind(
  t(sapply(split(as.data.frame(ab_parc), sub("_.*", "", rownames(ab_parc))),
           function(d) estimadores(as.matrix(d)))),
  total = estimadores(ab_parc))
knitr::kable(est, digits = 1, caption = "Riqueza observada e estimada por caixetal e no total.")

5. Diversidade alfa, beta e gama

Whittaker (1960) separou a diversidade em três níveis:

  • alfa (\(\alpha\)): diversidade dentro de cada unidade (média das parcelas ou dos locais);
  • gama (\(\gamma\)): diversidade total da região;
  • beta (\(\beta\)): diferença de composição entre as unidades.

Na forma multiplicativa, \(\beta = \gamma / \bar\alpha\) (quantas “unidades completamente diferentes” existem); na forma aditiva, \(\beta = \gamma - \bar\alpha\) (quantas espécies faltam, em média, em cada unidade).

particao <- function(m) {
  alfa <- mean(rowSums(m > 0)); gama <- sum(colSums(m) > 0)
  c(alfa = alfa, gama = gama, beta_mult = gama / alfa, beta_adit = gama - alfa)
}

rbind(
  `parcelas dentro de chauas` = particao(ab_parc[grepl("chauas", rownames(ab_parc)), ]),
  `parcelas dentro de jureia` = particao(ab_parc[grepl("jureia", rownames(ab_parc)), ]),
  `parcelas dentro de retiro` = particao(ab_parc[grepl("retiro", rownames(ab_parc)), ]),
  `entre os caixetais`        = particao(ab_local)
) |> round(2)

Se a beta entre os caixetais se aproxima de 3 (o número de locais), quase não há espécies em comum: cada caixetal funciona como uma comunidade diferente, apesar de todos serem dominados pela caixeta.
