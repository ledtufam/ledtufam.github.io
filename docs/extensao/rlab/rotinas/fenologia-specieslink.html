Calendário fenológico a partir de registros de herbário (speciesLink)

Fenologia
Dendrologia
Herbários e biodiversidade
Baixar registros de uma espécie no speciesLink, identificar flores e frutos nas anotações das exsicatas e construir calendários fenológicos por mês.
Autor

LEDT/UFAM

Nível: iniciante/intermediário · Pacotes: jsonlite (download); o restante usa R básico · Disciplina: FGD921 - Dendrologia Tropical · Baixar script

As exsicatas guardam, na etiqueta, quando a planta foi coletada e, muitas vezes, se tinha flores ou frutos. Juntando centenas de registros de herbários, é possível montar um calendário fenológico, ou seja, os meses em que a espécie floresce e frutifica. Essa informação é útil para planejar a coleta de sementes e entender a ecologia reprodutiva da espécie.

Fluxo da rotina: baixar registros → identificar flor/fruto na etiqueta → contar por mês → calendário.

1. Baixar os registros do speciesLink

O speciesLink tem um serviço web aberto, mas cada consulta exige uma chave de acesso (API key):

  1. Crie uma conta gratuita no speciesLink.
  2. Gere sua chave em specieslink.net/aut/profile/apikeys.
  3. Guarde a chave no R sem colocá-la no script que você vai compartilhar. Por exemplo, rode uma vez usethis::edit_r_environ(), escreva SPLINK_KEY=sua_chave no arquivo, salve e reinicie o R.

Os blocos desta seção não são executados no site (dependem da internet e da sua chave). A partir da seção 2 usamos dados de exemplo.

library(jsonlite)

baixar_splink <- function(especie, chave = Sys.getenv("SPLINK_KEY"), limite = 5000) {
  url <- paste0("https://specieslink.net/ws/1.0/search?",
                "scientificname=", URLencode(especie),
                "&scope=p&limit=", limite,
                "&apikey=", chave)
  res <- fromJSON(url)
  res$features$properties          # tabela com um registro por linha
}

reg <- baixar_splink("Handroanthus serratifolius")
nrow(reg)
names(reg)

As colunas que vamos usar são monthCollected (mês da coleta), occurrenceRemarks (anotações da etiqueta), stateProvince e scientificName.

Prefere baixar pelo site?

Na busca do speciesLink, pesquise a espécie, use Download para baixar os registros e leia o arquivo no R, por exemplo com reg <- read.delim("dados/speciesLink.txt"). Os nomes das colunas podem mudar um pouco (por exemplo, monthcollected em vez de monthCollected). Confira com names(reg) e ajuste a rotina.

3. Identificar flor e fruto nas etiquetas

As etiquetas não têm um campo padronizado de fenologia. Por isso, procuramos palavras-chave nas anotações. Ajuste a lista conforme o idioma e o estilo das etiquetas da sua espécie.

txt <- tolower(reg$occurrenceRemarks)

termos_flor  <- c("\\bflor", "\\bfl\\.", "\\bflower", "\\bbot[aã]o", "\\bbot[oõ]es", "\\bflora[cç][aã]o", "\\bantese")
termos_fruto <- c("\\bfrut", "\\bfr\\.", "\\bfruit")

reg$flor  <- grepl(paste(termos_flor,  collapse = "|"), txt)
reg$fruto <- grepl(paste(termos_fruto, collapse = "|"), txt)

# registros sem mês ou sem informação de fenologia não entram no calendário
reg <- subset(reg, !is.na(monthCollected) & monthCollected %in% 1:12)
c(total = nrow(reg), com_flor = sum(reg$flor), com_fruto = sum(reg$fruto),
  sem_info = sum(!reg$flor & !reg$fruto))
    total  com_flor com_fruto  sem_info 
      240       125        82        59

Confira uma amostra à mão! Leia algumas dezenas de etiquetas classificadas e veja se a busca por palavras acertou. Expressões como “sem flores” ou “flor-de-ipê” (nome popular) podem gerar falsos positivos.

Versão circular

O calendário circular deixa claro que dezembro e janeiro são vizinhos:

calendario_circular <- function(contagem, cor, titulo = "") {
  ang <- pi / 2 - (0:11) * 2 * pi / 12            # janeiro no topo, sentido horário
  r   <- contagem / max(contagem)
  plot(NA, xlim = c(-1.25, 1.25), ylim = c(-1.25, 1.25), asp = 1, axes = FALSE,
       xlab = "", ylab = "", main = titulo)
  for (k in c(.25, .5, .75, 1)) symbols(0, 0, circles = k, inches = FALSE, add = TRUE, fg = "grey85")
  for (i in 1:12) {
    a <- seq(ang[i] + pi / 12, ang[i] - pi / 12, length.out = 20)
    polygon(c(0, r[i] * cos(a), 0), c(0, r[i] * sin(a), 0), col = cor, border = "white")
  }
  text(1.15 * cos(ang), 1.15 * sin(ang), meses, cex = 0.8)
}

par(mfrow = c(1, 2), mar = c(0, 0, 2, 0))
calendario_circular(calendario$flor,  cores["flor"],  "Floração")
calendario_circular(calendario$fruto, cores["fruto"], "Frutificação")

6. Mês médio e concentração (estatística circular)

Como os meses formam um ciclo, a média comum não funciona (a média entre dezembro e janeiro não é junho!). Usamos a média circular: cada registro vira um ângulo, e calculamos o ângulo médio e o comprimento do vetor médio (r), que vai de 0 (fenofase espalhada no ano todo) a 1 (todos os registros no mesmo mês).

media_circular <- function(m) {
  ang <- (m - 0.5) * 2 * pi / 12
  C <- mean(cos(ang)); S <- mean(sin(ang))
  ang_medio <- atan2(S, C) %% (2 * pi)
  c(mes_medio = round(ang_medio * 12 / (2 * pi) + 0.5, 1), r = round(sqrt(C^2 + S^2), 2))
}

rbind(Floração     = media_circular(reg$monthCollected[reg$flor]),
      Frutificação = media_circular(reg$monthCollected[reg$fruto]))
             mes_medio    r
Floração           7.4 0.61
Frutificação       9.1 0.52

Um mes_medio de 8,5 corresponde à segunda quinzena de agosto. Valores de r acima de 0,5 indicam uma fenofase bem concentrada no ano.

Para discutir na prática
  • Em que meses você planejaria uma expedição para coletar sementes dessa espécie?
  • O padrão muda entre estados (stateProvince)? Repita a análise separando por região.
  • Que vieses os dados de herbário têm? Pense em quando e onde os coletores costumam ir a campo e em quais plantas eles preferem coletar.
