Parâmetros fitossociológicos e estrutura

Fitossociologia
Ecologia
Densidade, frequência, dominância, IVI e IVC por caixetal, e distribuição de diâmetros e alturas, com os dados abertos caixeta.
Autor

LEDT/UFAM

Nível: iniciante/intermediário · Pacotes: apenas R básico · Disciplina: FGD320 - Fitossociologia · Baixar script · Baixar dados caixeta · Baixar planilha Excel

Nesta rotina calculamos a estrutura horizontal (densidade, frequência, dominância e valor de importância) e a estrutura diamétrica e vertical dos caixetais do Vale do Ribeira, usando o mesmo banco da prática de índices de agregação. Usamos só funções do R básico, para que cada passo da fórmula fique visível.

Roteiro da aula prática (09/10 · EE4)
  1. Calcular os parâmetros de uma espécie à mão (seção 3) e conferir no Excel;
  2. Generalizar o cálculo para todas as espécies com uma função (seção 4);
  3. Comparar os três caixetais (seção 5) e montar a estrutura diamétrica (seção 6);
  4. Responder aos exercícios (seção 7).

1. Dados

Os dados caixeta vêm da dissertação de Andrea Vanin (1999), disponibilizados pelo curso ecoR/USP: três caixetais (chauas, jureia e retiro), cada um com 5 parcelas de 10 × 20 m. Cada linha é um fuste.

cx$h_m    <- cx$h * fator_h
cx$dap    <- cx$cap_cm / pi                     # DAP (cm)
cx$g      <- pi * cx$dap^2 / 40000              # área basal do fuste (m²) = CAP²/(4π)/10000

2. De fustes para árvores

A densidade conta árvores, mas a dominância soma a área basal de todos os fustes. Por isso, juntamos os fustes de cada árvore, somando a área basal e guardando a maior altura e o número de fustes:

cx$parc <- paste(cx$local, cx$parcela, sep = "_")
chave   <- c("local", "parc", "arvore", "especie")

arv <- aggregate(g ~ local + parc + arvore + especie, data = cx, FUN = sum)
arv$h_m     <- aggregate(h_m ~ local + parc + arvore + especie, data = cx, FUN = max)$h_m
arv$fustes  <- aggregate(fuste ~ local + parc + arvore + especie, data = cx, FUN = length)$fuste
arv$dap_eq  <- sqrt(arv$g * 40000 / pi)        # DAP equivalente (cm) de uma árvore com vários fustes

O DAP equivalente é o diâmetro de um fuste único com a mesma área basal da árvore: \(DAP_{eq} = \sqrt{\sum DAP_j^2}\).

3. Passo a passo com uma espécie

As fórmulas (Mueller-Dombois & Ellenberg 1974; Felfili et al. 2011):

Parâmetro Fórmula
Densidade absoluta (ind./ha) \(DA_i = n_i / A\)
Densidade relativa (%) \(DR_i = 100 \cdot n_i / N\)
Frequência absoluta (%) \(FA_i = 100 \cdot u_i / U_T\)
Frequência relativa (%) \(FR_i = 100 \cdot FA_i / \sum FA\)
Dominância absoluta (m²/ha) \(DoA_i = G_i / A\)
Dominância relativa (%) \(DoR_i = 100 \cdot G_i / \sum G\)
Valor de importância \(VI_i = DR_i + FR_i + DoR_i\) (ou dividido por 3, em %)
Valor de cobertura \(VC_i = DR_i + DoR_i\)

em que \(n_i\) = árvores da espécie i, \(N\) = total de árvores, \(A\) = área amostrada (ha), \(u_i\) = parcelas com a espécie, \(U_T\) = total de parcelas e \(G_i\) = área basal da espécie (m²).

Para Myrcia sulfiflora, considerando as 15 parcelas (15 × 200 m² = 0,3 ha):

A  <- 15 * 10 * 20 / 10000           # 0,3 ha
UT <- 15
m  <- arv[arv$especie == "Myrcia sulfiflora", ]

n_i <- nrow(m);                  N <- nrow(arv)
u_i <- length(unique(m$parc))
G_i <- sum(m$g);                 G <- sum(arv$g)

c(DA = n_i / A, DR = 100 * n_i / N, FA = 100 * u_i / UT,
  DoA = G_i / A, DoR = 100 * G_i / G)

4. Uma função para todas as espécies

fitossociologia <- function(d, A, UT) {
  n_i <- tapply(d$g, d$especie, length)
  u_i <- tapply(d$parc, d$especie, function(x) length(unique(x)))
  G_i <- tapply(d$g, d$especie, sum)
  FA  <- 100 * u_i / UT
  f <- data.frame(
    especie = names(n_i), n = as.integer(n_i),
    DA  = n_i / A,  DR  = 100 * n_i / sum(n_i),
    FA  = FA,       FR  = 100 * FA / sum(FA),
    DoA = G_i / A,  DoR = 100 * G_i / sum(G_i)
  )
  f$VI <- f$DR + f$FR + f$DoR
  f$VC <- f$DR + f$DoR
  f <- f[order(f$VI, decreasing = TRUE), ]
  rownames(f) <- NULL
  f
}

5. Comparando os três caixetais

Cada caixetal tem 5 parcelas (0,1 ha). Aplicamos a mesma função a cada local:

por_local <- lapply(split(arv, arv$local), fitossociologia, A = 0.1, UT = 5)

resumo <- t(sapply(split(arv, arv$local), function(d) c(
  arvores_ha = nrow(d) / 0.1,
  G_m2_ha    = round(sum(d$g) / 0.1, 1),
  riqueza    = length(unique(d$especie)),

6. Estrutura diamétrica e vertical

Em florestas naturais, a distribuição de diâmetros costuma ter a forma de J invertido: muitas árvores finas e poucas grossas. Usamos classes de 5 cm de DAP equivalente e de 2 m de altura:

classes_d <- seq(0, ceiling(max(arv$dap_eq) / 5) * 5, by = 5)
classes_h <- seq(0, ceiling(max(arv$h_m) / 2) * 2, by = 2)

par(mfrow = c(2, 3), mar = c(4, 4, 2, 1))
