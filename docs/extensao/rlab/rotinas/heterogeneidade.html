Índices de heterogeneidade: Shannon, Simpson e Pielou

Fitossociologia
Diversidade
Riqueza, índices de Shannon e Simpson, equabilidade de Pielou, números de Hill e teste t de Hutcheson para comparar os caixetais, com os dados abertos caixeta.
Autor

LEDT/UFAM

Nível: iniciante/intermediário · Pacotes: apenas R básico · Disciplina: FGD320 - Fitossociologia · Baixar script · Baixar dados caixeta

Uma comunidade é mais heterogênea (ou diversa) quando tem mais espécies (riqueza) e quando os indivíduos estão distribuídos de forma mais equilibrada entre elas (equabilidade). Os índices de heterogeneidade combinam esses dois componentes num único número.

Os caixetais são um ótimo exemplo: uma espécie, a caixeta, domina a comunidade. Como isso aparece nos índices?

Roteiro da aula prática (23/10 · EE6)
  1. Calcular à mão, no R, os índices para um caixetal (seção 2);
  2. Comparar os três caixetais com uma função (seção 3) e testar a diferença entre os índices de Shannon (seção 4);
  3. Ver os índices como números de Hill (seção 5) e o efeito da espécie dominante (seção 6);
  4. Responder aos exercícios (seção 7).

2. Passo a passo: o caixetal da Jureia

Índice Fórmula Interpretação
Riqueza \(S\) número de espécies
Shannon \(H' = -\sum p_i \ln p_i\) incerteza em prever a espécie do próximo indivíduo
Simpson (dominância) \(D = \sum \frac{n_i(n_i-1)}{N(N-1)}\) probabilidade de dois indivíduos sorteados serem da mesma espécie
Gini-Simpson \(1 - D\) probabilidade de serem de espécies diferentes
Simpson inverso \(1/D\) número “efetivo” de espécies dominantes
Pielou \(J' = H' / \ln S\) equabilidade, de 0 a 1

em que \(p_i = n_i / N\) é a proporção de indivíduos da espécie i.

n <- ab["jureia", ]
n <- n[n > 0]                  # só as espécies presentes
N <- sum(n); S <- length(n)
p <- n / N

H <- -sum(p * log(p))
D <- sum(n * (n - 1)) / (N * (N - 1))
J <- H / log(S)

c(N = N, S = S, Shannon = round(H, 3), Simpson_D = round(D, 3),
  Gini_Simpson = round(1 - D, 3), Simpson_inv = round(1 / D, 2), Pielou = round(J, 3))

Qual logaritmo? Usamos o logaritmo natural (\(\ln\), log() no R), e o resultado é dado em nats. Alguns trabalhos usam \(\log_2\) (bits) ou \(\log_{10}\). Os valores mudam, então só compare índices calculados com a mesma base.

3. Os três caixetais

heterogeneidade <- function(n) {
  n <- n[n > 0]; N <- sum(n); S <- length(n); p <- n / N
  H <- -sum(p * log(p)); D <- sum(n * (n - 1)) / (N * (N - 1))
  c(N = N, S = S, Shannon = H, Simpson_D = D, Gini_Simpson = 1 - D,
    Simpson_inv = 1 / D, Pielou = H / log(S))
}

het <- t(apply(ab, 1, heterogeneidade))

4. Os índices de Shannon diferem? Teste t de Hutcheson

Hutcheson (1970) propôs um teste t para comparar dois valores de \(H'\), usando a variância de cada um:

\[\text{Var}(H') = \frac{\sum p_i (\ln p_i)^2 - (\sum p_i \ln p_i)^2}{N} + \frac{S - 1}{2N^2}\]

\[t = \frac{H'_1 - H'_2}{\sqrt{\text{Var}(H'_1) + \text{Var}(H'_2)}}, \qquad gl = \frac{[\text{Var}(H'_1) + \text{Var}(H'_2)]^2}{\text{Var}(H'_1)^2/N_1 + \text{Var}(H'_2)^2/N_2}\]

hutcheson <- function(n1, n2) {
  v <- function(n) {
    n <- n[n > 0]; N <- sum(n); S <- length(n); p <- n / N
    H <- -sum(p * log(p))
    c(H = H, var = (sum(p * log(p)^2) - sum(p * log(p))^2) / N + (S - 1) / (2 * N^2), N = N)
  }
  a <- v(n1); b <- v(n2)
  t  <- (a["H"] - b["H"]) / sqrt(a["var"] + b["var"])
  gl <- (a["var"] + b["var"])^2 / (a["var"]^2 / a["N"] + b["var"]^2 / b["N"])
  c(H1 = a[["H"]], H2 = b[["H"]], t = t[[1]], gl = gl[[1]], p = 2 * pt(-abs(t[[1]]), gl[[1]]))
}

pares <- combn(rownames(ab), 2)

5. Números de Hill: uma família de índices

Riqueza, Shannon e Simpson podem ser vistos como membros de uma mesma família, os números de Hill (\(^qD\)), expressos em número efetivo de espécies:

  • \(^0D = S\) (riqueza: todas as espécies contam igualmente);
  • \(^1D = \exp(H')\) (espécies pesam pela abundância);
  • \(^2D = 1 / \sum p_i^2\) (só as espécies dominantes pesam).

Quanto mais rápido o perfil cai com \(q\), mais desigual é a comunidade.

hill <- function(n, q) {
  p <- n[n > 0] / sum(n)
  if (q == 1) exp(-sum(p * log(p))) else sum(p^q)^(1 / (1 - q))
}
qs <- seq(0, 3, by = 0.1)
perfis <- sapply(rownames(ab), function(l) sapply(qs, function(q) hill(ab[l, ], q)))

matplot(qs, perfis, type = "l", lty = 1, lwd = 2, col = cores[colnames(perfis)],
        xlab = "Ordem q", ylab = "Número efetivo de espécies")
