Padrão espacial: índices de agregação e distribuições de probabilidade

Fitossociologia
Ecologia
Índices de MacGuinnes, Fracker e Brischle, Payandeh, não aleatorizado, Hazen e Morisita, e ajuste das distribuições de Poisson e binomial negativa.
Autor

LEDT/UFAM

Nível: iniciante/intermediário · Pacotes: apenas R básico · Disciplina: FGD320 - Fitossociologia · Baixar script · Baixar dados caixeta

Os indivíduos de uma espécie podem estar distribuídos no espaço de forma aleatória, regular (uniforme) ou agregada. Com dados de inventário em parcelas de área fixa, esse padrão pode ser estimado por índices de agregação, que comparam o número de árvores por parcela com o esperado se a distribuição fosse aleatória.

O que todos os índices precisam é de uma tabela com quantas árvores de cada espécie há em cada parcela.

Roteiro da aula prática
  1. Preparar o RStudio e importar os dados caixeta (seção 0 e 1);
  2. Calcular à mão, no R, os índices para uma espécie, passo a passo (seção 2);
  3. Repetir para outra espécie, sozinho(a) (Sua vez!);
  4. Automatizar o cálculo para todas as espécies e interpretar (seções 3 a 5);
  5. Responder aos exercícios (seção 6).

0. Antes de começar

  1. Abra o RStudio e crie um projeto: File → New Project → New Directory → New Project, com o nome pratica_agregacao.
  2. Dentro da pasta do projeto, crie uma pasta dados/ e salve nela o arquivo caixeta.csv.
  3. Tenha à mão as tabelas de qui-quadrado e F usadas em aula, para comparar com os valores calculados no R.
  4. Crie um script novo (File → New File → R Script), salve como agregacao.R e vá copiando os blocos de código desta página. Use o botão de copiar no canto de cada bloco.

Nesta prática usamos apenas o R básico: não é preciso instalar pacotes.

Índice de MacGuinnes (\(IGA_i\))

Compara a densidade observada com a esperada se a distribuição fosse aleatória:

\[D_i = \frac{n_i}{U_T} \qquad d_i = -\ln\left(1 - \frac{U_i}{U_T}\right) \qquad IGA_i = \frac{D_i}{d_i}\]

D_i <- n_i / UT
d_i <- -log(1 - U_i / UT)      # log() no R é o logaritmo natural (ln)
IGA <- D_i / d_i
c(D_i = D_i, d_i = d_i, IGA = IGA)
       D_i        d_i        IGA 
 5.2666667  0.4054651 12.9891982

Interpretação: \(IGA_i\) < 1 uniforme; = 1 aleatório; entre 1 e 2 tendência ao agrupamento; > 2 agregado.

Índice de Fracker e Brischle (\(K_i\))

\[K_i = \frac{D_i - d_i}{d_i^2}\]

K <- (D_i - d_i) / d_i^2
K
[1] 29.569

Interpretação: \(K_i\) ≤ 0,15 aleatório; entre 0,15 e 1 tendência ao agrupamento; > 1 agregado.

Índice de Payandeh (\(P_i\))

Relação entre a variância e a média do número de árvores por parcela:

\[P_i = \frac{S_i^2}{M_i}\]

P <- S2 / M_i
P
[1] 13.22242

Interpretação: \(P_i\) ≤ 1 aleatório; entre 1 e 1,5 tendência ao agrupamento; > 1,5 agregado.

Índice não aleatorizado (\(R_i\)) e índice de Hazen (\(IH_i\))

O índice não aleatorizado é igual ao de Payandeh (\(R_i = S_i^2 / M_i\)), mas a decisão é feita por um teste de qui-quadrado. A estatística do teste é o próprio índice de Hazen:

\[\chi^2_i = IH_i = \frac{S_i^2}{M_i}(U_T - 1)\]

IH <- P * (UT - 1)
IH
[1] 185.1139

Em vez de procurar o valor na tabela impressa, usamos a função qchisq(), com \(U_T - 1\) graus de liberdade:

gl <- UT - 1
c(chi2_75 = qchisq(0.75, gl), chi2_95 = qchisq(0.95, gl), chi2_99 = qchisq(0.99, gl))

As tabelas de qui-quadrado e F usadas em aula estão neste PDF (Santana & Ranal, Análise da germinação: um enfoque estatístico; reproduzidas de Rohlf & Sokal 1995). Na tabela de qui-quadrado, procure a linha \(\nu = U_T - 1 = 14\) e a coluna do nível de significância \(\alpha\) (lembre que 95% de probabilidade corresponde a \(\alpha = 0{,}05\)):

Valor crítico Coluna da tabela Tabela impressa R
\(\chi^2\) a 95% \(\alpha = 0{,}05\) 23,685 qchisq(0.95, 14) = 23,685
\(\chi^2\) a 99% \(\alpha = 0{,}01\) 29,141 qchisq(0.99, 14) = 29,141
\(\chi^2\) a 75% \(\alpha = 0{,}25\) não consta qchisq(0.75, 14) = 17,117
\(F\) a 95% (14 e ∞ gl) \(\nu_1 = 14\), \(\nu_2 = 240\) (última linha) ≈ 1,73 qf(0.95, 14, Inf) = 1,692

Repare que a tabela não traz a coluna de 75% (usada no índice de Hazen) nem a linha de infinitos graus de liberdade (usada no teste de Morisita). Nesses casos, o R resolve: qchisq() e qf() dão o valor exato para quaisquer graus de liberdade.

Interpretação:

  • Não aleatorizado: se \(\chi^2_i\) > \(\chi^2_{95\%}\), o desvio da aleatoriedade é significativo e a espécie é agregada; caso contrário, aleatória.
  • Hazen: se \(IH_i\) < \(\chi^2_{75\%}\), não agrupada; se \(IH_i\) > \(\chi^2_{99\%}\), agrupada; entre os dois, tendência ao agrupamento.
IH > qchisq(0.95, gl)      # não aleatorizado: agregada?
[1] TRUE
IH > qchisq(0.99, gl)      # Hazen: agrupada?
[1] TRUE

Índice de Morisita (\(IM_i\)) e teste F

\[IM_i = U_T \frac{\sum_j n_{ij}(n_{ij}-1)}{n_i(n_i-1)} \qquad F_i = \frac{IM_i(n_i-1) + U_T - n_i}{U_T - 1}\]

IM  <- UT * sum(n_ij * (n_ij - 1)) / (n_i * (n_i - 1))
F_i <- (IM * (n_i - 1) + UT - n_i) / (UT - 1)
F_tab <- qf(0.95, df1 = UT - 1, df2 = Inf)     # F tabelado: UT-1 e infinito gl
c(IM = IM, F = F_i, F_tabelado = F_tab)
        IM          F F_tabelado 
  3.193768  13.222423   1.691771

Interpretação: \(IM_i\) = 1 aleatório; < 1 uniforme; > 1 agregado. O desvio é significativo se \(F_i\) > \(F\) tabelado.

3. Resumo das fórmulas

Para cada espécie i, com \(n_{ij}\) = número de árvores na parcela j, \(n_i\) = total de árvores, \(U_i\) = parcelas em que ocorre e \(U_T\) = total de parcelas:

Índice Fórmula Interpretação
MacGuinnes \(IGA_i = D_i / d_i\), com \(D_i = n_i/U_T\) e \(d_i = -\ln(1 - U_i/U_T)\) < 1 uniforme; = 1 aleatório; 1–2 tendência ao agrupamento; > 2 agregado
Fracker e Brischle \(K_i = (D_i - d_i) / d_i^2\) ≤ 0,15 aleatório; 0,15–1 tendência; > 1 agregado
Payandeh \(P_i = S_i^2 / M_i\) ≤ 1 aleatório; 1–1,5 tendência; > 1,5 agregado
Não aleatorizado \(R_i = S_i^2 / M_i\), testado por \(\chi^2_i = R_i (U_T - 1)\) \(\chi^2\) significativo (95%, \(U_T-1\) gl): agregado; senão, aleatório
Hazen \(IH_i = \frac{S_i^2}{M_i}(U_T - 1)\) < \(\chi^2_{0,75}\) não agrupado; > \(\chi^2_{0,99}\) agrupado; entre os dois, tendência
Morisita \(IM_i = U_T \frac{\sum n_{ij}(n_{ij}-1)}{n_i(n_i-1)}\), testado por \(F_i = \frac{IM_i(n_i-1) + U_T - n_i}{U_T - 1}\) = 1 aleatório; < 1 uniforme; > 1 agregado (se \(F_i\) for significativo)

em que \(M_i\) é a média e \(S_i^2\) a variância (com \(U_T - 1\) no denominador) do número de árvores por parcela.

No índice de Fracker e Brischle usamos a diferença \(D_i - d_i\) com sinal, como nas tabelas de Souza e Soares (2014): valores negativos indicam padrão aleatório ou uniforme.

4. Uma função para calcular todas as espécies

Fazer espécie por espécie dá trabalho. A função abaixo reúne os mesmos cálculos da seção 2 e os aplica a todas as linhas da tabela de uma vez, já classificando o padrão. Copie a função inteira e rode.

indices_agregacao <- function(tab, UT = ncol(tab)) {
  n_i <- rowSums(tab)                       # total de árvores
  U_i <- rowSums(tab > 0)                   # parcelas com a espécie
  M_i <- n_i / UT                           # média por parcela
  S2  <- apply(tab, 1, function(x) sum((x - mean(x))^2) / (UT - 1))  # variância

  # MacGuinnes e Fracker & Brischle (indefinidos se a espécie ocorre em todas as parcelas)
  D_i <- n_i / UT
  d_i <- ifelse(U_i < UT, -log(1 - U_i / UT), NA)
  IGA <- D_i / d_i
  K   <- (D_i - d_i) / d_i^2

  # Payandeh / não aleatorizado / Hazen
  P   <- S2 / M_i
  qui <- P * (UT - 1)                       # = IH (índice de Hazen)

  # Morisita e teste F
  IM  <- UT * rowSums(tab * (tab - 1)) / (n_i * (n_i - 1))
  F_i <- (IM * (n_i - 1) + UT - n_i) / (UT - 1)

  # Valores críticos
  chi95 <- qchisq(0.95, UT - 1)
  chi75 <- qchisq(0.75, UT - 1)
  chi99 <- qchisq(0.99, UT - 1)
  F95   <- qf(0.95, UT - 1, Inf)

  classe <- function(x, cortes, rotulos) as.character(cut(x, cortes, rotulos, right = TRUE))

  data.frame(
    n_i, U_i, D_i = round(D_i, 2), d_i = round(d_i, 2),
    S2 = round(S2, 2), M_i = round(M_i, 2),
    IGA = round(IGA, 2), K = round(K, 2), P = round(P, 2),
    IH = round(qui, 2), IM = round(IM, 2), F = round(F_i, 2),
    IGA_cl = ifelse(is.na(IGA), "-", ifelse(abs(IGA - 1) < 1e-9, "Aleat.",
             classe(IGA, c(-Inf, 1, 2, Inf), c("Unif.", "T.Agr.", "Agreg.")))),
    K_cl   = ifelse(is.na(K), "-", classe(K, c(-Inf, 0.15, 1, Inf), c("Aleat.", "T.Agr.", "Agreg."))),
    P_cl   = classe(P, c(-Inf, 1, 1.5, Inf), c("Aleat.", "T.Agr.", "Agreg.")),
    R_cl   = ifelse(qui > chi95, "Agreg.", "Aleat."),
    IH_cl  = ifelse(qui < chi75, "Não agr.", ifelse(qui > chi99, "Agreg.", "T.Agr.")),
    IM_cl  = ifelse(F_i > F95, "Agreg.", ifelse(IM < 1, "Unif.", "Aleat.")),
    check.names = FALSE
  )
}

A escala importa: a caixeta dentro de cada local

Várias espécies ocorrem em apenas um dos três locais (veja a tabela do passo 1). Com as 15 parcelas juntas, parte da “agregação” reflete a diferença entre caixetais, e não o arranjo das árvores dentro de cada um. Para a caixeta, que ocorre nos três locais, podemos repetir a análise separadamente:

caixeta_local <- t(sapply(split(arv, arv$local), function(d) {
  parcelas <- unique(d$parc)                               # 5 parcelas do local
  n <- sapply(parcelas, function(p) sum(d$parc == p & d$especie == "Tabebuia cassinoides"))
  r <- indices_agregacao(matrix(n, nrow = 1), UT = length(parcelas))
  unlist(r[, c("n_i", "M_i", "S2", "P", "IM", "P_cl", "R_cl", "IM_cl")])
}))

Para pensar
  • Os índices nem sempre concordam, principalmente na faixa de “tendência ao agrupamento”. O índice de Payandeh tende a classificar mais espécies como agregadas que o de MacGuinnes. Por isso é comum apresentar mais de um índice e discutir as diferenças.
  • Os índices de MacGuinnes e Fracker e Brischle ficam indefinidos quando a espécie ocorre em todas as parcelas (\(U_i = U_T\)), como na Tabela 1.4 do livro para Siparuna arianae.
  • O índice de Payandeh não tem uma classe “uniforme”: espécies regulares aparecem como aleatórias (\(P_i \leq 1\)).
  • Compare a caixeta nas 15 parcelas e dentro de cada local. O que muda? O que isso diz sobre o tamanho e a distribuição das unidades amostrais?

7. Para saber mais: conferindo com o livro

Os índices de MacGuinnes, Fracker e Brischle e Payandeh podem ser calculados só a partir de \(n_i\), \(U_i\) e \(S_i^2\). Vamos conferir com três espécies da Tabela 1.4 de Souza e Soares (2014), inventário da Mata da Silvicultura em Viçosa (MG), com \(U_T = 10\) parcelas:

livro <- data.frame(
  especie = c("Anadenanthera peregrina", "Cecropia hololeuca", "Ocotea pretiosa"),
  n_i = c(76, 9, 41), U_i = c(8, 6, 9), S2 = c(53.60, 0.77, 10.54)
)
UT_livro <- 10
D <- livro$n_i / UT_livro
d <- -log(1 - livro$U_i / UT_livro)
data.frame(livro["especie"],
           IGA = round(D / d, 2),
           K   = round((D - d) / d^2, 2),
           P   = round(livro$S2 / D, 2))
                  especie  IGA     K    P
1 Anadenanthera peregrina 4.72  2.31 7.05
2      Cecropia hololeuca 0.98 -0.02 0.86
3         Ocotea pretiosa 1.78  0.34 2.57

Os valores batem com os do livro: A. peregrina (IGA = 4,72; K = 2,31; P = 7,05), C. hololeuca (0,98; −0,02; 0,85) e O. pretiosa (1,78; 0,34; 2,57). Diferenças na segunda casa decimal vêm do arredondamento de \(S_i^2\) na tabela do livro.

8. Distribuições de probabilidade

Outra forma de avaliar o padrão é verificar qual distribuição de probabilidade descreve melhor o número de indivíduos por parcela: Poisson (padrão aleatório) ou binomial negativa (padrão agregado).

Usamos o exemplo de Souza e Soares (2014): uma área de 9 ha dividida em 100 parcelas de 30 × 30 m, com 44 indivíduos da espécie A.

n_ind     <- 0:4                        # nº de indivíduos por parcela
n_parcelas <- c(73, 18, 3, 4, 2)        # nº de parcelas (Tabela 1.5)
N  <- sum(n_parcelas)                   # 100 parcelas
mu <- sum(n_ind * n_parcelas) / N       # média = 0,44 indivíduo/parcela
mu
[1] 0.44

Poisson

\[P(x) = e^{-\mu}\frac{\mu^x}{x!}\]

p_pois <- dpois(n_ind, lambda = mu)
p_pois <- c(p_pois, 1 - sum(p_pois))    # inclui a classe "> 4"
esp_pois <- N * p_pois
data.frame(x = c(n_ind, ">4"), P = round(p_pois, 4), Esperado = round(esp_pois, 2))
   x      P Esperado
1  0 0.6440    64.40
2  1 0.2834    28.34
3  2 0.0623     6.23
4  3 0.0091     0.91
5  4 0.0010     0.10
6 >4 0.0001     0.01

Binomial negativa

A binomial negativa tem dois parâmetros: a média \(\mu\) e o expoente \(k\), estimado inicialmente por \(\hat{k} = \bar{X}^2 / (S^2 - \bar{X})\):

S2 <- (sum(n_ind^2 * n_parcelas) - sum(n_ind * n_parcelas)^2 / N) / N   # como no livro (denominador n)
k  <- mu^2 / (S2 - mu)
c(S2 = S2, k = k)
       S2         k 
0.7864000 0.5588915 
p_bn <- dnbinom(n_ind, size = k, mu = mu)   # mesmo que as fórmulas P(0), P(1)... do livro
p_bn <- c(p_bn, 1 - sum(p_bn))
esp_bn <- N * p_bn
data.frame(x = c(n_ind, ">4"), P = round(p_bn, 4), Esperado = round(esp_bn, 2))
   x      P Esperado
1  0 0.7229    72.29
2  1 0.1780    17.80
3  2 0.0611     6.11
4  3 0.0230     2.30
5  4 0.0090     0.90
6 >4 0.0061     0.61

Teste de aderência (qui-quadrado)

\[\chi^2 = \sum \frac{(FO_i - FE_i)^2}{FE_i}\]

obs <- c(n_parcelas, 0)                 # nenhuma parcela com mais de 4 indivíduos

qui_pois <- sum((obs - esp_pois)^2 / esp_pois)
qui_bn   <- sum((obs - esp_bn)^2 / esp_bn)
n_cl     <- length(obs)                 # 6 classes

data.frame(
  Modelo     = c("Poisson", "Binomial negativa"),
  qui2_obs   = round(c(qui_pois, qui_bn), 2),
  gl         = c(n_cl - 2, n_cl - 3),
  qui2_tab   = round(c(qchisq(0.95, n_cl - 2), qchisq(0.95, n_cl - 3)), 3),
  Ajuste     = ifelse(c(qui_pois < qchisq(0.95, n_cl - 2),
                        qui_bn   < qchisq(0.95, n_cl - 3)), "Aceito", "Rejeitado")
)
             Modelo qui2_obs gl qui2_tab    Ajuste
1           Poisson    52.89  4    9.488 Rejeitado
2 Binomial negativa     4.82  3    7.815    Aceito

A Poisson é rejeitada e a binomial negativa se ajusta aos dados: a espécie A tem padrão agregado. Os valores de \(\chi^2\) diferem um pouco dos do livro (53,20 e 4,79) porque o R não arredonda as probabilidades intermediárias.

O qui-quadrado fica instável quando as frequências esperadas são muito pequenas (< 5). Em trabalhos, é recomendável juntar as últimas classes (por exemplo, “3 ou mais”) antes do teste (Krebs 1999).

m <- rbind(Observado = obs, Poisson = esp_pois, `Binomial negativa` = esp_bn)
colnames(m) <- c(n_ind, ">4")
barplot(m, beside = TRUE, col = c("grey60", "#6cc3d5", "#78c2ad"), border = NA,
        xlab = "Número de indivíduos por parcela", ylab = "Número de parcelas",
        legend.text = TRUE, args.legend = list(bty = "n"))

9. E se eu tiver as coordenadas das árvores?

Com a posição (x, y) de cada árvore, é possível usar a função K de Ripley, que avalia o padrão em diferentes distâncias. O pacote spatstat faz isso:

library(spatstat)
pts <- ppp(arv$x, arv$y, window = owin(c(0, 100), c(0, 100)))  # parcela de 100 x 100 m
L   <- envelope(pts, Lest, nsim = 99)       # L(r): versão estabilizada de K(r)
plot(L, . - r ~ r, main = "")                # acima do envelope = agregação
