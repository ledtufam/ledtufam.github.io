Espectros NIR: do arquivo bruto à discriminação de espécies

Espectroscopia NIR
Taxonomia
Fluxo do curso Herbarium Spectroscopy with MicroNIR: gerar a matriz no ISC Reader App, ajustar e recortar os comprimentos de onda, remover leituras problemáticas, calcular médias por exsicata e discriminar espécies de Handroanthus com LDA e validação leave-one-out.
Autor

LEDT/UFAM

Nível: intermediário · Pacotes: MASS (já vem com o R) · Baixar script · Baixar a matriz espectral · Baixar os metadados

Esta rotina reproduz o fluxo de trabalho do curso Herbarium Spectroscopy with MicroNIR: theory and practice, realizado em abril de 2025 no Herbário do INPA pelo projeto SPECTRA POP. A rotina usa os dados reais do curso: espectros NIR de exsicatas de ipês (Handroanthus, Bignoniaceae), gênero com espécies listadas na CITES.

O fluxo tem duas partes, como no curso:

  1. Preparação dos dados: arquivos brutos → matriz espectral → ajuste dos comprimentos de onda → recorte → controle de qualidade → médias por exsicata;
  2. Análise discriminante: LDA com validação cruzada leave-one-out (LOO), matriz de confusão e acurácia com intervalo de confiança.
Dados e scripts originais

Vasconcelos, C. & Durgante, F. (2025). R codes and datasets used in the course “Herbarium Spectroscopy with MicroNIR: theory and practice” (v1.0.0). Zenodo. https://doi.org/10.5281/zenodo.15531968 (licença CC BY-SA 4.0)

Os scripts originais do curso (com ggplot2, dplyr e caret) estão no GitHub. Aqui o mesmo fluxo foi reescrito em R básico, passo a passo, e os resultados são idênticos.

Os dados

  • 59 exsicatas do Herbário INPA de cinco espécies: Handroanthus barbatus, H. impetiginosus, H. incanus, H. ochraceus e H. serratifolius;
  • espectrômetro portátil NIR-S-G1 (InnoSpectra), faixa de 900 a 1700 nm, medindo reflectância;
  • cerca de 4 leituras por face da folha, abaxial (ab) e adaxial (ad), num total de 474 arquivos _r.csv.

Parte 1. Preparação dos dados

1. Gerar a matriz espectral no ISC Reader App

Cada leitura do NIR-S-G1 gera um arquivo .csv com um cabeçalho de configuração (modelo, número de série, data, temperatura etc.) e uma tabela de comprimento de onda × reflectância. O ISC Reader App junta todos esses arquivos numa única tabela.

  1. Baixe o arquivo spectrapop-course-workflow.zip no Zenodo e descompacte. Os arquivos brutos estão em Datasets/Readings_from_micronir/.
  2. Abra o ISC Reader App e marque Tipo de dado: Reflectância.
  3. Em Selecione os arquivos brutos (.csv), clique em Browse… e selecione todos os arquivos _r.csv (Ctrl + A). Aguarde até aparecer Upload complete.
  4. Confira os espectros nas abas Tabela, Espectros e PCA.
  5. Clique em Download CSV e salve o arquivo na pasta dados/ do seu projeto do RStudio, com o nome matriz_isc_handroanthus.csv.

Se preferir pular esta etapa, baixe a matriz já pronta no topo desta página. Ela é exatamente a saída do app para os 474 arquivos.

3. Ajustar os comprimentos de onda

Repare nas células vazias (NA) da matriz. Cada aparelho tem uma calibração própria e mede em comprimentos de onda ligeiramente diferentes (por exemplo, 901,70 nm em um e 900,86 nm em outro). 6. Médias por exsicata: três conjuntos de dados

As várias leituras de uma mesma folha não são independentes: a unidade de análise é a exsicata. Calculamos o espectro médio de cada exsicata em três conjuntos de dados, como no curso:

  1. abaxial + adaxial (todas as leituras);
  2. só abaxial;
  3. só adaxial.
media_exsicata <- function(sel) {
  g <- factor(info$barcode[sel])
  M <- rowsum(X[sel, ], g) / as.vector(table(g))
  data.frame(especie = meta$especie[match(rownames(M), meta$barcode)],
             barcode = rownames(M), M, check.names = FALSE, row.names = NULL)
}

Parte 2. Análise discriminante

7. LDA com validação leave-one-out

A análise discriminante linear (LDA) encontra as combinações de comprimentos de onda que melhor separam as espécies. Para saber se o modelo funciona com exsicatas novas, usamos a validação leave-one-out (LOO): retiramos uma exsicata, ajustamos o modelo com as demais, classificamos a exsicata retirada e repetimos para todas.

Além da espécie prevista, a LDA dá a probabilidade posterior de cada espécie. Como no curso, cada previsão é classificada em quatro tipos:

Tipo Significado
Correta (significativa) espécie certa, com probabilidade > 0,95
Correta (não significativa) espécie certa, com probabilidade ≤ 0,95
Incorreta (significativa) espécie errada, com probabilidade > 0,95
Incorreta (não significativa) espécie errada, com probabilidade ≤ 0,95 
library(MASS)

lda_loo <- function(d) {
  Xd <- as.matrix(d[, -(1:2)])               # só as colunas espectrais
  y  <- factor(d$especie)
  res <- data.frame(barcode = d$barcode, observada = y, prevista = NA, prob = NA)
  post <- matrix(NA, nrow(d), nlevels(y), dimnames = list(NULL, levels(y)))

  for (i in seq_len(nrow(d))) {
    modelo   <- suppressWarnings(lda(Xd[-i, ], grouping = y[-i]))   # ajusta sem a exsicata i
    previsao <- predict(modelo, Xd[i, , drop = FALSE])              # classifica a exsicata i
    res$prevista[i] <- as.character(previsao$class)
    res$prob[i]     <- max(previsao$posterior)
    post[i, ]       <- previsao$posterior
  }

  res$tipo <- paste0(ifelse(res$prevista == res$observada, "Correta", "Incorreta"),
                     ifelse(res$prob > 0.95, " (significativa)", " (não significativa)"))
  res$prevista <- factor(res$prevista, levels = levels(y))
  cbind(res, round(post, 4))
}

O suppressWarnings() esconde o aviso de variáveis colineares: comprimentos de onda vizinhos são muito correlacionados. O curso usa a LDA diretamente sobre os 199 comprimentos de onda, sem pré-processamento.

Matriz de confusão e acurácia

A acurácia é a proporção de exsicatas classificadas corretamente. O intervalo de confiança de 95% vem do teste binomial exato (o mesmo que a função confusionMatrix() do pacote caret, usada no curso, calcula):

acuracia <- function(loo) {
  acertos <- sum(loo$prevista == loo$observada)
  ic <- binom.test(acertos, nrow(loo))$conf.int
  c(acuracia = 100 * acertos / nrow(loo), IC_inf = 100 * ic[1], IC_sup = 100 * ic[2])
}

plot_confusao <- function(conf, titulo = "") {
  k <- nrow(conf)
  par(mar = c(8, 9, 3, 1))
  image(1:k, 1:k, t(conf[k:1, ]), col = colorRampPalette(c("white", "firebrick"))(20),
        axes = FALSE, xlab = "", ylab = "", main = titulo, cex.main = 0.95)
  axis(1, 1:k, colnames(conf), las = 2, font = 3, cex.axis = 0.85)
  axis(2, 1:k, rev(rownames(conf)), las = 1, font = 3, cex.axis = 0.85)
  mtext("Prevista", side = 1, line = 6.5); mtext("Observada", side = 2, line = 7.5)
  for (i in 1:k) for (j in 1:k) text(j, k - i + 1, conf[i, j], cex = 1.2)
  box()
}
ac <- acuracia(loo)
plot_confusao(conf, sprintf("Abaxial + Adaxial | %.1f%% (IC 95%%: %.1f–%.1f)", ac[1], ac[2], ac[3]))

Interpretação

Usando as duas faces juntas, cerca de 88% das exsicatas são classificadas corretamente, contra cerca de 75% só com a face abaxial e 86% só com a adaxial. Combinar as leituras das duas faces dá a melhor discriminação.

Veja também os tipos de previsão: a maior parte dos acertos tem probabilidade alta (> 0,95), e as previsões com probabilidade baixa concentram os erros. Na prática, exsicatas classificadas com baixa probabilidade, ou incorretamente com alta probabilidade, merecem uma revisão da identificação.

Cuidados
  • Valide sempre no nível da exsicata (ou do indivíduo), nunca da leitura. Se leituras da mesma folha caem no treino e no teste ao mesmo tempo, a acurácia fica inflada.
  • Com poucas exsicatas por espécie (como H. ochraceus, com 7), os resultados variam bastante. Amostre mais indivíduos sempre que possível.
  • Para ir além, teste pré-processamentos (SNV, derivadas de Savitzky-Golay, com o pacote prospectr) e outros classificadores (PLS-DA, random forest), sempre com a mesma validação.
